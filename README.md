# UMC-BCK-APP
UMC-BCK — multi-vertical e-commerce marketplace for Kaduna State, Nigeria (built for national expansion). Covers general marketplace, canteen ordering, phones &amp; tech, gold &amp; jewelry, automobile, and pharma &amp; medical, with wallet-only payments and real-time delivery dispatch. Backend: Supabase (Postgres, Auth, Storage, RLS). Frontend: React.
