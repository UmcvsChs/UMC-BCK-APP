# Supabase Migrations — UMC-BCK

**This exceeds GitHub's 100-file web-upload limit**, so migrations ship as two separate zips: `migrations-batch8-part1.zip` (65 files) and `migrations-batch8-part2.zip` (64 files). Both need to land in the same `supabase/migrations` folder — upload part 1's loose files first, commit, then navigate back into that same folder and upload part 2's files, commit. Select and drag the `.sql` files themselves, not the extracted folder, or you'll create an unwanted subfolder.
